## 各文件核心内容

### 精读笔记

* 精读章节：Ch2（学科简史）、Ch3（反思工具）、Ch5（技术与关系）、Ch8（指导网络）、Ch20（批判方法）、Ch23（数字技术）
* 每章按固定结构：核心问题 → 论点 → 概念 → 方法 → 争论 → 启发 → 可引用点 → 来源
* 末尾包含全书综合：学科画像、CS 背景入行需补的三个观念、实验室建设建议

### 术语表

* Sheet 1：精读章节术语表，152 条，含英文术语、建议译法、实际译法、一致性、位置
* Sheet 2：全书核心术语一致性，30 条，含全书范围的译法分布统计
* Sheet 3：校对方法、局限与下一步建议

### 检查预备

* 15 个问题分三类：书讲了什么（5）、怎么理解（5）、对工作有什么用（5）
* 三分钟口头总结讲稿（约 600 字）
* 两周精读计划（14 天，每天 2–2.5 小时）

## 已知局限

1. **术语表的自动抽取率**：依赖模式匹配，可能遗漏不含英文原词的纯中文段落
2. **全书粗扫覆盖度**：仅覆盖 30 个核心术语，非精读章节的其他术语未做一致性检查
3. **PDF 抽文本质量**：少数页面可能存在 PDF 解析错位，影响极个别英文原文引用的精确性
4. **字数控制**：第 23 章笔记偏长（含综合部分），其余章节均在 800–1200 字范围
5. **译法建议**：部分建议基于通行用法判断，未逐一查证国内正式出版物
